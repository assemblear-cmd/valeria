# FORMA — шаблон сайта студии движения

Самостоятельный адаптивный лендинг, собранный по композиционной логике сайта-референса: крупная типографика, фотогалерея направлений, блок о студии, события, спецпредложения, форма записи и контакты.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## Где менять данные

Основной контент находится в `src/content.js`. Там можно заменить:

- название и подпись бренда;
- пункты меню;
- заголовки и описания;
- направления и события;
- цены;
- телефон, почту, адрес и соцсети.

Изображения лежат в `public/images`. Новые файлы можно положить в эту папку и указать путь вида `/images/your-photo.jpg` в `src/content.js`.

Форма сейчас работает как демонстрация на клиентской стороне. Перед публикацией подключите её к почте, CRM или сервису обработки форм.

## Структура

```text
public/images/     — изображения сайта
src/content.js     — весь редактируемый контент
src/main.js        — разметка и интерактив
src/styles.css     — дизайн и адаптив
```
